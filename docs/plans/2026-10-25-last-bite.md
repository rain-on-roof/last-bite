# Last Bite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, dependency-free browser game where you chew a sandwich on a park bench and must stop before the goose strikes.

**Architecture:** A pure, seeded state machine (`src/game.js`) owns goose AI and scoring and emits events; a Canvas 2D renderer draws the park, goose rig, sandwich and effects from that state; `src/main.js` wires input, loop, screens, audio and sharing.

**Tech Stack:** HTML, ES modules, Canvas 2D, WebAudio, `node:test` (Node 24). No build step, no runtime dependencies.

**Spec:** `docs/specs/2026-10-25-last-bite-design.md`

## Global Constraints

- No runtime dependencies, no CDN, no build step; must run from GitHub Pages as plain files.
- Portrait 9:16 logical canvas 540×960, scaled to devicePixelRatio; letterboxed on desktop.
- English default; `ru`/`uk` from `navigator.language`.
- Challenge link format: `#beat=<int>` with 1 ≤ int ≤ 99999.
- Golden Goose probability 1/25 per run, double points.
- No AI co-author trailers in commits.

### Task 2: Game state machine

**Files:** Create `src/game.js`, `tests/game.test.js`

**Produces:**
- `createGame({ seed: number, golden?: boolean }) => Game`
- `step(game, dt: number, chewing: boolean) => Event[]` (mutates `game`)
- `rankFor(score: number) => string` (rank key: `crumb|snack|regular|legend|whisperer`)
- `Game` fields read by renderer: `phase ('play'|'over')`, `time`, `score`, `golden`,
  `sandwich { size, left }`, `sandwiches`, `goose { dist, mood, moodTime, moodLength, suspicion }`
- `mood ∈ 'idle'|'creep'|'tell'|'innocent'|'strike'`, `dist ∈ [0.18, 1]` (1 = far)
- Events `{ type }`: `bite`, `sandwich`, `step`, `tell`, `fakeout`, `innocent`, `strike`

Rules: bite every 0.26 s of chewing (+1, or +2 golden). Sandwich of `size` bites; next is `size + 2`.
Chewing raises suspicion (faster when close) and makes the goose creep; stillness decays it.
At the run's threshold the goose enters `tell`. At tell end: chewing → `strike`, phase `over`;
not chewing → `innocent` and suspicion drops. Some tells are fake-outs: they end early with
`fakeout` and the goose returns to `creep` whatever the player does. Tell length shrinks with score
to a floor.

- [ ] Write tests:

```js
import test from 'node:test'; import assert from 'node:assert/strict';
import { createGame, step, rankFor } from '../src/game.js';
const DT = 1 / 60;
function run(g, secs, chewing, sink = []) { for (let t = 0; t < secs; t += DT) { sink.push(...step(g, DT, typeof chewing === 'function' ? chewing(g) : chewing)); if (g.phase === 'over') break; } return sink; }

test('chewing scores bites', () => {
  const g = createGame({ seed: 1 }); const ev = run(g, 1, true);
  assert.ok(g.score >= 3); assert.equal(ev.filter(e => e.type === 'bite').length, g.score);
});
test('never chewing never strikes', () => {
  const g = createGame({ seed: 2 }); run(g, 60, false); assert.equal(g.phase, 'play'); assert.equal(g.score, 0);
});
test('chewing nonstop is eventually punished', () => {
  for (let s = 1; s <= 20; s++) { const g = createGame({ seed: s }); run(g, 60, true); assert.equal(g.phase, 'over', 'seed ' + s); }
});
test('releasing on every tell survives', () => {
  for (let s = 1; s <= 20; s++) {
    const g = createGame({ seed: s }); run(g, 60, g2 => g2.goose.mood !== 'tell');
    assert.equal(g.phase, 'play', 'seed ' + s); assert.ok(g.score > 20, 'seed ' + s + ' score ' + g.score);
  }
});
test('golden doubles points', () => {
  const g = createGame({ seed: 3, golden: true }); run(g, 0.6, true); assert.equal(g.score % 2, 0); assert.ok(g.score >= 4);
});
test('finishing a sandwich serves a bigger one', () => {
  const g = createGame({ seed: 4 }); const first = g.sandwich.size;
  const ev = run(g, 60, g2 => g2.goose.mood !== 'tell');
  assert.ok(ev.some(e => e.type === 'sandwich')); assert.ok(g.sandwich.size > first);
});
test('some tells are fake-outs', () => {
  let fake = 0; for (let s = 1; s <= 30; s++) { const g = createGame({ seed: s }); fake += run(g, 40, g2 => g2.goose.mood !== 'tell').filter(e => e.type === 'fakeout').length; }
  assert.ok(fake > 0);
});
test('rank ladder', () => {
  assert.equal(rankFor(0), 'crumb'); assert.equal(rankFor(200), 'whisperer');
  const order = [0, 10, 30, 60, 100, 200].map(rankFor); assert.deepEqual([...new Set(order)].length >= 5, true);
});
```

### Task 4: Goose rig

**Files:** Create `src/render/goose.js`

**Produces:** `drawGoose(ctx, view)` where `view = { x, y, scale, mood, moodT (0..1), time, golden, walk (0..1), strikeT }`.

Parts: feet (orange webbed), body (teardrop, white/grey cel shading), wing (folds, flaps on strike and
ruffle), neck (spline through 4 points, S-curve idle → low and stretched in tell → straight lunge in
strike), head, orange beak (opens on honk/hiss, teeth-like serrations for comedy), eye with pupil and
an angry brow that lowers with suspicion. Poses: idle bob, creep waddle, tell (head low, neck forward,
feathers ruffle, tremble), innocent (head turned up/away, eyes closed, whistle), strike (lunge, beak wide,
wings spread). Golden variant recolours to gold with sparkle.
